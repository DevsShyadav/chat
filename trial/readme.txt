== Description ==

This is the **24-hour free trial** of WP AI Chatbot. It includes every feature of the full Pro version:

* BYOK support (OpenAI GPT-5.4, Google Gemini 2.5, Groq LLaMA 4)
* Auto-trains on your site content (posts, pages, products)
* Fully customizable chat widget (white + green theme)
* Smart email fallback
* Analytics dashboard
* Custom Q&A pairs
* Rate limiting & security

= How the trial works =

1. Activate the plugin — a 24-hour countdown timer appears at the top of your admin.
2. Use every feature, completely free, for 24 hours.
3. When the timer reaches zero, the trial **automatically deactivates and deletes itself** — no leftover data, no manual cleanup.
4. Love it? Upgrade to Pro for lifetime access (no recurring fees).

== Installation ==

1. Upload the trial ZIP via Plugins > Add New > Upload Plugin
2. Activate — the 24-hour countdown starts immediately
3. Go to AI Chatbot > Settings, add your AI API key
4. Train on content and go live!
